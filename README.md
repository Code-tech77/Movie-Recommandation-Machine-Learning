# 🎬 Week 10 Project: Movie Recommendation System using Machine Learning

## 🚀 Overview
This project is part of **Week 10** of the Microsoft-affiliated Data Science Internship.  
The goal is to build a **Movie Recommendation System** using machine learning techniques to suggest relevant movies based on user preferences and similarity patterns.

---

## 🎯 Objectives
- Build a recommendation system for movies
- Analyze movie metadata and user preference patterns
- Apply similarity-based machine learning techniques
- Generate personalized movie recommendations

---

## 🧠 Key Concepts

🎬 **Recommendation Systems**  
Systems that suggest items (movies) to users based on similarity or behavior patterns.

🎬 **Content-Based Filtering**  
Recommends movies based on similarity of features such as genre, cast, and description.

🎬 **Similarity Metrics**  
Uses mathematical measures (e.g., cosine similarity) to find relationships between movies.

---

## 🛠️ Technologies Used
- Python 🐍  
- Pandas

- Scikit-learn

- Seaborn  

---

## ⚙️ Project Workflow

### 1. Data Collection & Cleaning
- Load movie dataset
- Handle missing values
- Clean and preprocess text features

### 2. Feature Engineering
- Extract key features (genre, keywords, overview)
- Convert text data into numerical vectors

### 3. Similarity Computation
- Apply cosine similarity to measure movie relationships
- Build similarity matrix between movies

### 4. Recommendation System
- Input a movie title
- Generate top similar movie recommendations

---

## 📊 Key Insights
- Movies with similar content tend to share audience preferences
- Text features (overview, genre) are powerful for recommendations
- Similarity-based models can effectively personalize suggestions

## 💡 Key Learnings
- Understanding recommendation system fundamentals
- Working with text-based feature engineering
- Applying similarity metrics in machine learning
- Building practical AI systems for personalization
